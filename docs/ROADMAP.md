# OrchAI Roadmap

## V0.1 (MVP) - The Foundation
- Local CLI tool initialization
- Project context extraction
- Task creation and parsing
- Prompt compilation
- Antigravity adapter integration
- Git diff inspection and rollback
- Structured execution report parsing

## V0.2 - Governance and State
- Policy engine implementation (allowed/forbidden paths)
- Human approval gate (CLI prompts)
- Task state machine (Lifecycle management)
- Basic verification execution (running shell commands for tests)

## V0.3 - Optimization and Memory
- Context optimization and token reduction
- Engineering memory persistence
- Execution analytics and token tracking

## V0.4 - Extensibility
- Multi-agent support architecture
- Generic Agent adapter framework
- Model Context Protocol (MCP) integration

## V1.0 - The Control Plane
- Web dashboard interface
- ChatGPT/Web integration
- Advanced governance rules
- Advanced analytics
- Team workflows
- Cloud orchestration capabilities

## Future
- Agent marketplace
- Plugin ecosystem
- Advanced learning from executions
- Enterprise governance
- CI/CD integration
- Issue tracker integration (GitHub, Jira, Linear)
