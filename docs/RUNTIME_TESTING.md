# Runtime Testing

Real runtime testing avoids destructive operations by isolating agent actions in a disposable runtime fixture or testing specific sandboxed Git contexts.

## CLI Workflow
`orchai runtime doctor` - Displays the current local capability bindings.
`orchai runtime test` - Runs the full 10-step validation matrix (Blocked if Authentication is unavailable).

## Capabilities
Statuses cycle from `UNVERIFIED` -> `MOCK_VERIFIED` -> `RUNTIME_VERIFIED`.
A capability is never assumed supported; evidence must be generated by a successful `RuntimeTestResult`.
